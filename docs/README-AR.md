# دليل المشروع بالعربية — اتفقنا

## ما الذي نبنيه؟
**اتفقنا (Etfago)** هو مساحة مشتركة لتنظيم الاتفاقات بين الأفراد والشركات. ينشئ أحد الأطراف اتفاقًا يتضمن بنودًا واضحة، ويدعو الآخرين، ثم يراجع كل طرف **النسخة نفسها** ويعلن موافقته داخل المنصة أو يطلب تعديلًا. بعد الموافقة يستطيع الأطراف متابعة الالتزامات، وعند أي تعديل جديد تبقى النسخة المعتمدة السابقة كما هي إلى أن تتم الموافقة على نسخة جديدة.

> هذا التطبيق لإدارة الاتفاقات والموافقات التشغيلية، وليس منصة توقيع قانوني معتمد أو وسيلة للتحقق من الهوية الحقيقية للأطراف.

## متطلبات أساسية
- يعمل للأفراد والشركات، ولا يشترط وجود مبلغ مالي أو موعد في كل اتفاق.
- حسابات مستخدمين، ومساحة شخصية، ومساحات اختيارية للشركات.
- دعوات خاصة بالبريد، ولا يستطيع قبولها إلا الحساب الذي يملك البريد الإلكتروني المستهدف بعد التحقق منه.
- البنود منظمة، ولكل نسخة رقم وتاريخ وسجل مراجعة مستقل.
- الموافقة مرتبطة بإصدار محدد؛ ولا تصبح النسخة معتمدة إلا بعد موافقة جميع الأطراف المطلوبة.
- التعديلات الجديدة لا تغيّر النسخة الحالية المعتمدة حتى تتم مراجعتها والموافقة عليها.
- تعليقات على البنود، وتتبع الالتزامات والمسؤوليات، وسجل نشاط، وواجهة عربية RTL مع English.
- مرفقات وصور وPDF مع وصول محمي، وتصدير نسخة قابلة للطباعة.

## التخزين والتقنيات
**تم اعتماد تخزين المرفقات على السيرفر نفسه بدل S3.** تُحفظ الملفات في مجلد خاص دائم على VPS عبر Docker bind mount، ولا تُوضع في `public/`. تحتفظ PostgreSQL بالبيانات الوصفية فقط، ويتم تحميل الملفات عبر Route Handler يتحقق من صلاحية المستخدم في كل مرة. النسخ الاحتياطية يجب أن تشمل قاعدة البيانات ومجلد الملفات معًا.

التقنيات: Next.js App Router، TypeScript، Tailwind CSS v4، shadcn/ui، PostgreSQL، Prisma، Auth.js، Zod، React Hook Form، next-intl، وResend للبريد.

## المراحل
1. **الأساس:** الإعداد والمستخدمون ومساحات العمل والصلاحيات.
2. **الاتفاقات:** إنشاء المسودات والبنود المرنة.
3. **المشاركة:** الدعوات والتحقق من البريد والصلاحيات لكل اتفاق.
4. **الموافقات:** نسخ غير قابلة للتغيير بعد الإرسال، ومراجعة وموافقة لكل طرف، وسجل واضح.
5. **التعديلات:** اقتراح التغييرات والمقارنة والتعليقات.
6. **وظائف المنتج:** الالتزامات والمرفقات والإشعارات والتصدير.
7. **الجودة والإطلاق:** الاختبارات والأمان وتجربة الهاتف والنسخ الاحتياطية والنشر.
